## 2. Local Development Workflow

To run the project locally:

```bash
# 1. Navigate to the backend directory
cd backend

# 2. Run database migrations (already up to date)
python manage.py migrate

# 3. Start development server
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser. All templates and static assets will load directly from `frontend/templates/` and `frontend/static/`.

## 3. Render Deployment Configuration

When deploying this project as a **Web Service** on **Render.com**:

### Service Settings

| Setting | Value |
|---|---|
| **Environment** | `Python` |
| **Root Directory** | `backend` |
| **Build Command** | `./build.sh` |
| **Start Command** | `gunicorn edutrust.wsgi:application` |

### Build Script (`backend/build.sh`)
```bash
#!/usr/bin/env bash
set -o errexit

pip install -r requirements.txt
python manage.py collectstatic --no-input
```

### Static Asset Serving (WhiteNoise)
WhiteNoise is configured in `backend/edutrust/settings.py` using `whitenoise.middleware.WhiteNoiseMiddleware` and `CompressedStaticFilesStorage`. During `./build.sh`, `collectstatic` packages all assets from `../frontend/static/` into `backend/staticfiles/` with Brotli and Gzip compression.

## 4. Required Environment Variables on Render

Configure these in the Render Dashboard under **Environment**:

| Variable | Recommended Production Value | Description |
|---|---|---|
| `PYTHON_VERSION` | `3.11.9` or `3.12.3` | Python runtime version on Render |
| `SECRET_KEY` | *(A long random 50+ character string)* | Django production secret key |
| `DEBUG` | `False` | Disables debug mode for security |
| `ALLOWED_HOSTS` | `.onrender.com,localhost,127.0.0.1` | Allowed hostnames |
| `RENDER_EXTERNAL_HOSTNAME` | *(Auto-populated by Render)* | Render will inject your app subdomain |

## 5. Media & Database Persistence Note for Render

> [!IMPORTANT]
> **Ephemeral Disk Warning on Render Free/Starter Instances:**
> - Render web service disks are ephemeral by default. File uploads saved to `backend/media/` and changes to local `db.sqlite3` will reset whenever the service redeploys or restarts unless persistent storage is attached.
> - **For persistent media:** Attach a Render Persistent Disk mounted at `/var/data` (and set `MEDIA_ROOT = '/var/data/media'`), or configure AWS S3 / Cloudinary using `django-storages`.
> - **For persistent database in production:** Provision a managed Render PostgreSQL database and set `DATABASE_URL` with `dj-database-url`.
